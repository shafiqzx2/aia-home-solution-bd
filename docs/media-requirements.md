# Owner media checklist

The current imagery and SVG illustrations are temporary concepts. They do not demonstrate actual products in stock, completed installations, clients, or professional credentials. Keep the explicit concept labels until approved replacements are published.

| Placement                     | Current treatment                                                                      | Required approved asset                                                                                                                                                              |
| ----------------------------- | -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Header / footer / request PDF | Typeset company name; separate nullable logo slots                                     | Transparent SVG or high-resolution PNG, approved light/dark variants, rights record, accessible name                                                                                 |
| Favicon                       | Temporary AIA text                                                                     | Approved square brand icon with SVG and raster variants                                                                                                                              |
| Hero                          | Existing 1536 × 1024 architectural concept with a source-aligned SVG chase             | Higher-resolution original if available; preserve composition and image rights                                                                                                       |
| Richer physical relighting    | Lightweight bright segment over the baked-in fixture                                   | Unlit and lit plates, fixture mask, reflection and light-spill layers, or approved layered 3D scene with camera information; a flattened image cannot independently relight the room |
| Home & Digital overview       | Existing SVG solution illustrations plus a labeled interior concept                    | Six relevant approved visuals: automation, lighting, surveillance, door access/controls, audio/digital setup, home/commercial planning                                               |
| Featured / catalog products   | Existing product illustrations; `images` array and shared gallery support replacements | Genuine product/model images, at least a cover and optional alternate views, manufacturer permissions, bilingual alt text, verified specifications                                   |
| Service previews and details  | Existing labeled interior concepts                                                     | Relevant real consultation, site assessment, planning, installation/setup imagery with participant/site consent; no unrelated stock photography                                      |
| Projects                      | Explicit concept gallery; no completed-project claim                                   | Actual cover, location, category, project description, gallery, approval, photography rights, client permission                                                                      |
| Reviews                       | Hidden until approved, consented data exists                                           | Genuine quote, name, optional approved photo, actual optional star rating/date, source and publication consent                                                                       |
| Clients / partners            | Hidden until authorized records exist                                                  | Approved relationship, supplied logo, permission and verified website where applicable                                                                                               |
| Satisfaction / trust metrics  | Hidden until verified records exist                                                    | Actual value, label, calculation basis/source, verified date, owner approval; never infer from concept content                                                                       |
| Careers / team                | No fabricated team images or vacancies                                                 | Approved portraits, roles, bios, consent and actual job information when ready                                                                                                       |

Use responsive, optimized images with stable aspect ratios and useful alt text. Product cards need roughly square assets; service cards use 4:3 imagery, with a mobile 16:10 crop. Check important subject placement at 320–1920px. Do not stretch a real product or add invented alternate views to fill a gallery.

Future media CMS: validate MIME and actual file signatures, cap size/dimensions, process images, store provenance/permission and bilingual alt text, track usages, support replacement/versioning, and prevent deleting assets still in use. Store future uploads in approved durable object storage; do not modify Docker volumes for this frontend phase.
